# PersonalAIOS 项目计划

> 文档状态：初稿（项目初始化阶段）
> 最后更新：2026-11-20
> 说明：本文档仅确定方向性内容，凡未确认项均标注「待确认」，不做技术假设。

## 1. 项目背景

个人日常工作中存在大量重复性、碎片化的信息处理与任务管理需求（如资料整理、待办跟踪、知识沉淀等）。现有通用工具之间彼此割裂，需要人工在多个应用间搬运信息，成本高且难以沉淀个人长期资产。

PersonalAIOS 的设想是构建一个以「个人」为中心、可逐步生长的 AI 操作系统式工作台，把任务、资料、知识和个人偏好集中管理，并通过 AI 能力降低信息处理成本。

> 待确认：项目发起人、要解决的首要真实痛点、是否有明确的目标用户范围（仅本人使用 / 小范围共享）。
