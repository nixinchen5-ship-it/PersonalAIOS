## 3. 验收标准

### 3.1 通用验收标准（适用于所有模块）

每个模块申请验收时，需同时满足：

1. 功能符合该模块需求说明，边界情况有明确处理。
2. 代码符合 [development-standards.md](./development-standards.md)。
3. 关键逻辑有对应测试，测试可重复执行且全部通过。
4. 无已知的阻塞性缺陷；非阻塞问题已登记到本文档「问题记录」。
5. 不引入未确认的依赖或技术方案。
6. 文档同步更新：模块说明、接口说明、配置项说明。
7. 不包含敏感信息与临时文件。

## 6. 验收流程

1. 开发完成 → 模块状态置为「待验收」。
2. 按第 3 节标准逐条自检，并在第 4 节登记测试记录。
3. 验收不通过时，问题登记到第 5 节，状态回退为「进行中」。
4. 验收通过后，模块状态置为「已通过」，并注明测试记录日期。
