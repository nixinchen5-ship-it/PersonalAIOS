# PersonalAIOS

面向个人使用、长期运行的 Windows 桌面 AI 助理系统。

> 当前状态：**项目初始化已完成，处于需求与技术方案确认阶段**。仓库仅包含目录骨架、项目文档与基础配置，尚未包含任何业务功能代码，也未安装任何依赖。

## 项目定位

PersonalAIOS 不是普通聊天机器人，也不只是任务管理或资讯聚合工具。它通过持续积累个人知识、经历、目标与偏好，让 AI 逐步理解使用者的背景与需求，在知识、行动和外部信息三个方向上提供长期辅助。

核心价值：持续了解我、记录我、辅助我做决策，并主动为我发现有价值的信息和机会。

定位约束：

- **单用户**：仅本人使用，不设计多用户与账号权限体系。
- **Windows 桌面**：先以本地 Web 应用开发，功能稳定后用 Electron 封装为桌面应用。
- **长期运行**：常驻后台、持续积累、持续演进。
- **以记忆为基础**：个人知识库与长期记忆是其他所有能力的前提。

## 四个业务模块

| 编号 | 模块 | 定位 | 首版 |
| --- | --- | --- | --- |
| B1 | 个人知识库与长期记忆 | 系统认知基础：个人资料、知识库、长期记忆、检索、来源追溯、个人上下文 | 是 |
| B2 | 个人助理与成长管理 | 核心业务：AI 对话、计划任务、状态与目标、成长档案、个性化建议 | 部分（仅 AI 对话） |
| B3 | 情报与机会发现 | 核心业务：新闻情报、每日简报、城市机会发现与匹配 | 否 |
| B4 | 系统管理与扩展 | 支撑：配置、模型设置、备份恢复、日志、健康检查、扩展预留 | 部分（最小能力） |

模块关系：B1 向 B2、B3 提供个人上下文；B2 与 B3 不直接互相依赖；B4 横向提供基础设施能力。详见 [项目计划](docs/project-plan.md)。

## 首版 MVP

首版只重点开发三项核心能力：**个人知识库**、**长期记忆**、**AI 对话**。计划管理、成长管理、情报与机会发现不进入首版验收范围。

## 六层技术架构

交互层 → 应用服务层 → 业务模块层（B1–B4）→ AI 能力层 → 数据访问层 → 存储层。

六层是逻辑分层，不是六个独立服务；首版采用模块化单体，不做微服务。详见 [技术架构](docs/technical-architecture.md)。

## 建议技术路线

TypeScript、Node.js、React、Vite、SQLite、轻量 ORM、云端 AI API、Electron（阶段 7 封装）、Git + GitHub、TRAE。

> 以上为建议路线，尚未完成技术初始化，具体版本与依赖待确认。
