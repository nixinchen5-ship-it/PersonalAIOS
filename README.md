# PersonalAIOS

Personal AI OS —— 面向个人使用、长期运行的 Windows 桌面 AI 助理系统。

> 当前状态：**项目初始化阶段**。仓库仅包含目录骨架、项目文档与基础配置，尚未包含任何业务功能代码，也未安装任何依赖。

## 项目定位

PersonalAIOS 不是一个聊天机器人，也不只是一个任务管理工具。它通过持续积累个人知识、经历、目标与偏好，让 AI 逐步理解使用者的个人背景与需求，在知识、行动和外部信息三个方向上提供长期辅助。

定位约束：

- **单用户**：仅本人使用，不设计多用户体系。
- **Windows 桌面**：以桌面常驻形态运行，提供悬浮球、快速对话、系统通知等入口（具体形态待确认）。
- **长期运行**：常驻后台、持续积累、持续演进。
- **以记忆为基础**：个人知识库与长期记忆是其余能力的前提。

## 业务模块

系统划分为五个业务模块，其中 B1 是整个系统的基础。

| 编号 | 模块 | 定位 | 首版 |
| --- | --- | --- | --- |
| B1 | 个人知识库与长期记忆 | 系统基础：资料管理、长期记忆、检索、来源追溯、个人上下文提供 | 是 |
| B2 | 个人发展与行动管理 | 核心业务：状态理解、目标与计划、任务追踪、提醒建议、成长记录与复盘、AI 对话 | 部分（仅 AI 对话） |
| B3 | 情报与机会中心 | 核心业务：信息采集、清洗去重、个性化筛选、机会匹配、简报与提醒 | 否 |
| B4 | 扩展管理 | 支撑：外部工具与服务的扩展管理 | 否（仅预留扩展空间） |
| B5 | 系统管理 | 支撑：配置、模型设置、备份恢复、日志、安全、运行状态 | 部分（最小配置与备份） |

模块关系：B1 向 B2、B3 提供个人上下文；B2、B3 不直接互相依赖；B4 为其他模块提供外部扩展能力；B5 横向提供基础设施能力。详见 [技术架构](docs/technical-architecture.md)。

### 首版 MVP

首版只做三项核心能力：**个人知识库**、**长期记忆**、**AI 对话**。其余能力不进入首版验收范围。
