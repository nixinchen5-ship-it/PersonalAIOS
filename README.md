# PersonalAIOS

个人 AI 操作系统（Personal AI OS）项目仓库。

> 当前状态：**项目初始化阶段**。仓库仅包含目录骨架、项目文档与基础配置，尚未包含任何业务功能代码，也未安装任何依赖。

## 项目定位

PersonalAIOS 设想成为一个以个人为中心、可逐步生长的 AI 工作台，把任务、资料、知识与个人偏好集中管理，并通过 AI 能力降低日常信息处理成本。

> 待确认：项目定位的具体边界、目标用户范围与不做什么。
